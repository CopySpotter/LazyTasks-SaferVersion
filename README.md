# LazyTasks-SaferVersion

**Der Computer darf beschäftigt sein. Sein Benutzer muss es nicht.**

Ein unabhängiges, noch im Aufbau befindliches Fork-Projekt auf Basis von **BusyTasks** von **Bernhard Mayr**: ein winziger Systemmonitor, der auf Wunsch **ständig im Vordergrund** bleibt, ohne ständig Aufmerksamkeit einzufordern.

**Lazy** = weniger Kontrollrituale. **Rock ’n’ Roll** = Freude am Experiment statt überflüssiger Perfektion. **Safer** = Systemnähe verantwortungsvoll gestalten, ohne Administratorpasswörter zu speichern.

## Philosophie

Der [philosophische Überbau](docs/PHILOSOPHIE.md) beschreibt die Ambivalenz permanenter Systembeobachtung und leitet daraus die Gestaltungsprinzipien des Projekts ab.
